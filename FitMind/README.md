# FitMind – webová aplikácia

Angular aplikácia FitMind. Popis projektu, architektúru a postup nasadenia nájdeš v [hlavnom README](../README.md).

```bash
npm install
npm start
```

| Príkaz | Čo robí |
| --- | --- |
| `npm start` | Vývojový server na `http://localhost:4200/` |
| `npm run build` | Produkčný build do `dist/FitMind/browser` |
| `npm test` | Unit testy |

Priečinok `backend/` je archív pôvodného Python backendu; aplikácia ho už nepoužíva.
